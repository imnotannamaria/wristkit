## Before you start

You need Next.js 15 or newer with App Router, Node.js 20 or newer, a Supabase project and an iPhone with your Apple Health data.

## 1. Install dependencies

```bash
pnpm add drizzle-orm postgres zod
```

## 2. Configure the server

Add these variables to `.env.local` and to your hosting provider's server environment:

```ini
WRISTKIT_DATABASE_URL=your-supabase-transaction-pooler-url
WRISTKIT_API_KEY=your-random-secret
```

Copy the **Transaction pooler** connection string from the Supabase connection dialog. Keep the database URL and API key on the server, without a `NEXT_PUBLIC_` prefix.

Generate a secret locally:

```bash
node -e 'console.log(require("crypto").randomBytes(32).toString("base64url"))'
```

## 3. Create the database tables

The **SQL migrations** bundle below reads the actual migration files from the registry. Run `0001_initial.sql` and then `0002_dedupe.sql` in the Supabase SQL editor. If an existing table contains duplicates, review the optional cleanup instructions in the second file before running it.

## 4. Copy the files

The bundles below include the destination of each file:

- **Sync route** goes into `app/api/wristkit-sync/route.ts`.
- **Activity Card and data helpers** includes the component, states, stylesheet, loader and database helpers.
- Copy `styles.css` alongside `states.tsx`; the component imports it automatically.

These code blocks are generated from the registry source at build time, so the demo and installation files stay in sync.

## 5. Render the card

Use the loader in a Server Component:

```tsx
import { TodayActivityCard, loadTodayActivity } from "@/components/wristkit/today-activity-card";

export default async function Page() {
  const state = await loadTodayActivity({ tz: "America/Sao_Paulo" });
  return <TodayActivityCard state={state} />;
}
```

Set `tz` to your timezone. The card supports loading, empty, error, stale and synced states. Goals are configurable values in this version; they are not imported from Apple Health.

## 6. Connect your iPhone

Follow [Shortcut setup](/docs/shortcut-setup), enter your deployed sync URL and API key, and run the Shortcut once. Check that the card receives your data before configuring an automation.

## Source files

Select each tab and copy its contents to the displayed destination.
