## Before you start

- Next.js 15 with App Router
- A [Supabase](https://supabase.com) project (free tier works fine)
- Node.js 20 or newer

## 1. Install the peer dependencies

In your project, install what the component and the handler need:

```bash
pnpm add drizzle-orm postgres zod
```

Or `npm install` / `yarn add` if that is your style. wristkit does not lock you in to a package manager.

## 2. Set your environment variables

Create a `.env.local` at the project root:

```
WRISTKIT_DATABASE_URL=postgresql://postgres:password@db.xxx.supabase.co:5432/postgres
WRISTKIT_API_KEY=replace-with-32-random-bytes
```

`WRISTKIT_DATABASE_URL` is your Supabase connection string. You can find it in Project Settings, Database, Connection string, URI. Use the **pooler** URL in production so the route handler can share connections.

`WRISTKIT_API_KEY` is a secret you pick yourself. The iOS Shortcut sends it in the `x-api-key` header on every POST. Generate one with:

```bash
node -e 'console.log(require("crypto").randomBytes(32).toString("base64url"))'
```

## 3. Run the SQL on Supabase

Open the **SQL Editor** in your Supabase dashboard and run both migrations from the **SQL migrations** bundle at the end of this page, in order. They create the `wristkit_samples` table and the unique index that protects against duplicate Shortcut posts.

## 4. Copy the route handler

Create `app/api/wristkit-sync/route.ts` in your project and paste the file from the **Route handler** bundle at the end of this page. The handler:

- Checks the API key with `crypto.timingSafeEqual`
- Rate limits each IP at 30 requests every 5 minutes
- Validates the payload with Zod
- Inserts the samples through Drizzle

## 5. Copy the component

Go to [TodayActivityCard](/docs/components/today-activity-card) and copy the files listed there into `components/wristkit/today-activity-card/` and `lib/wristkit/` in your project.

Then use it in a Server Component:

```tsx
import { TodayActivityCard, loadTodayActivity } from "@/components/wristkit/today-activity-card";

export default async function Page() {
  const state = await loadTodayActivity({ tz: "America/Sao_Paulo" });
  return <TodayActivityCard state={state} />;
}
```

`loadTodayActivity` accepts an optional `tz` for the day boundary and optional `goals` if you want to override the defaults (600 kcal, 30 min, 8000 steps).
