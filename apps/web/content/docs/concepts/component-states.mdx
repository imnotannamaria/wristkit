## The contract

Every component in the registry must handle these states:

```ts
type ComponentState =
  | { kind: "loading" }
  | { kind: "empty" }
  | { kind: "error"; message?: string }
  | { kind: "stale"; lastSync: Date }
  | { kind: "partial"; missing: string[] }
  | { kind: "ok"; data: T };
```

This isn't optional. The five-state contract is what makes wristkit components feel polished rather than janky. Real data is intermittent — the user revokes a Health permission, the Shortcut automation pauses, the Supabase connection drops. Components that only handle the `ok` state silently break.

## Design principles

**No new vocabulary.** Each state uses the same Panel grammar — dotted rules, mono labels, `//` footer notes, status pill. The card doesn't break character when data is missing.

**No generic error UI.** "Oops, something went wrong" is not acceptable. The error state shows a server-log-style block with the actual code, endpoint, and timestamp. An italic serif sentence translates the technical detail into plain language.

**Numbers vs nothing.** The stale state desaturates existing numbers to signal "old" rather than hiding them. The empty and error states use `—` (em dash) rather than `0` or blank — a zero would suggest the user burned zero calories, which is false.

**Actions in the footer.** Recovery copy lives in the footer where users already look for context. The empty state offers "install shortcut →". The stale state offers "retry →". No modals, no full-screen takeovers.

## State resolution

`loadTodayActivity()` (and every `load` function we ship) resolves the state for you:

```ts
export async function loadTodayActivity(): Promise<TodayState> {
  const url = process.env.WRISTKIT_DATABASE_URL;
  if (!url) return { kind: "error", message: "WRISTKIT_DATABASE_URL not set" };

  try {
    const r = await getTodayActivity(url);
    if (!r.lastSync) return { kind: "empty" };

    const missing = [
      r.kcal === null && "kcal",
      r.exerciseMinutes === null && "exercise_minutes",
      r.steps === null && "steps",
    ].filter(Boolean) as string[];

    const age = Date.now() - r.lastSync.getTime();
    if (age > 24 * 60 * 60 * 1000) return { kind: "stale", lastSync: r.lastSync, data };
    if (missing.length) return { kind: "partial", data, missing };
    return { kind: "ok", data };
  } catch (err) {
    return { kind: "error", message: err instanceof Error ? err.message : "unknown" };
  }
}
```

The component is a pure renderer. It receives `state` as a prop and renders the correct UI. It never fetches. This separation makes testing trivial and makes the component reusable across server and client boundaries.
