# wristkit

Apple Health, on the web — as React components.

`wristkit` is a CLI that installs production-ready React components for visualizing Apple Health data into any **Next.js 15 (App Router)** project. You bring your own Supabase. We bring the components, the handler, the SQL migration, and the iOS Shortcut.

## Quick start

```bash
npx wristkit init
npx wristkit add today-activity-card
```
